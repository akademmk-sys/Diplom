# Веб-сервер «Планировщик задач» (ToDo List)

Проект представляет собой бэкенд-приложение на языке Go с веб-интерфейсом. Основное назначение — планирование задач, отслеживание их статусов, безопасное хранение данных в базе данных SQLite

Выполнены все задачи со звездочкой

Настройка конфигурации (`.env`)
Создайте в корне проекта файл `.env` со следующими параметрами (или используйте значения по умолчанию):
```env
TODO_PORT=7540
TODO_DBFILE=scheduler.db
TODO_PASSWORD=myPass

команды Docker:

docker run -d -p 7540:7540 -v $(pwd)/scheduler.db:/app/scheduler.db --name todo-container todo-server
